# jacquesbelmont.com

Novo site pessoal de Jacques Belmont: engenharia de software, inteligência artificial, projetos acadêmicos e publicações científicas.

Stack: Astro estático + TypeScript + Markdown/MDX; hospedagem prevista: GitHub Pages.

O site atual e DNS não serão alterados durante a preparação desta versão.

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

## GitHub Pages

Em Settings → Pages, selecionar GitHub Actions. O endereço de prévia será `https://jacquesbelmont.github.io/jacquesbelmont.com/` somente após build e deploy bem-sucedidos.

**Pendências:** fotografia real, URL do vídeo, currículo verificado, imagens próprias dos projetos e publicações científicas verificadas. Nenhum DOI ou vínculo acadêmico será inventado.
